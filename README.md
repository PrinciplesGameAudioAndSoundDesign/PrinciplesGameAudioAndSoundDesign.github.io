# Principles of Game Audio and Sound Design

Here, you'll find supporting code, documentation, and the [official repository](https://github.com/PrinciplesGameAudioAndSoundDesign/PGASD-2ndEdition) for the 2nd edition of [Principles of Game Audio and Sound Design](https://www.routledge.com/Principles-of-Game-Audio-and-Sound-Design-Sound-Design-and-Audio-Implementation-for-Interactive-and-Immersive-Media/Sinclair-Cardona/p/book/9781041072430), by [Jean-Luc Sinclair](https://college.berklee.edu/faculty/jean-luc-sinclair) and [David Cardona](https://linktr.ee/dcbapc), published by [Routledge](https://www.routledge.com/).
